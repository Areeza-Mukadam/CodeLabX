# Semester 5 IIS practical materials

Place the Introduction to Intelligent Systems experiment PDFs in this folder. Use one file per practical where possible, with the experiment number and topic in the filename, for example `Exp-01-Topic.pdf`.

The current seed uses the five PDFs provided here: Experiments 01, 02, 03, 04, and 07. Experiments 05 and 06 were not present, so they have not been invented. Add more PDFs here and ask to ingest them; adding files alone does not change the application database. Avoid placing student submissions or personal information here.

The Experiment 01 handout mixes browser built-in API viva questions with a Gemini API/Flask implementation. Experiment 04 is about informed search, but its learning outcomes and viva questions appear to be copied from Experiment 03. These source inconsistencies are noted in the corresponding practical descriptions for faculty review.
