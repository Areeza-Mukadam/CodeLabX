# Semester 3 Data Structures experiment materials

Place experiment handouts and reference PDFs in this folder so they can be used to prepare or update the Semester 3 seed data.

Use one PDF per experiment when possible and include the experiment number and a short title in the filename, for example:

- `Exp-02-Stack-Using-Array.pdf`
- `Exp-05-Singly-Linked-List.pdf`
- `Exp-12-Mini-Project.pdf`

Keep the original document when it contains the official experiment list or common rubrics. Avoid putting student submissions or personal information here. After adding or replacing PDFs, ask to ingest the Semester 3 Data Structures experiment materials; the PDFs are source material and are not automatically imported just by being copied into this folder.

The official list used for the current seed is preserved at `docs/seed-inputs/Data Structure-Expt List.docx`.
